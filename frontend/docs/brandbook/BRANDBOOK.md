# Брендбук Федерации спортивного программирования России (ФСП)

Справочник фирменного стиля для проекта **HuntMe** (платформа-агрегатор ИТ-вакансий с верифицированным профилем
достижений участника ФСП).

> **Примечание по регламенту:** Брендбук не строгий. Все аспекты дизайна и UI/UX, которые в нем не охвачены (компоненты
> форм, таблицы, карточки, модальные окна, состояния элементов), проектируются самостоятельно в современном стиле, при
> этом строго сохраняются основные фирменные цвета, шрифты и общая эстетика.

## 2. Типографика и шрифты

### Основной шрифт: JetBrains Mono

- **Лицензия:** SIL Open Font License 1.1 (свободное коммерческое и некоммерческое использование).
- **Архив шрифта:** `docs/brandbook/JetBrainsMono-2.304.zip`.
- **Назначение:** фирменный стиль спортивного программирования — код, бейджи, теги технологий, числовые показатели,
  ранги, грейды, акцентные заголовки.
- **Подключение Google Fonts:**
  ```html
  <link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:ital,wght@0,100..800;1,100..800&family=Inter:wght@300..900&display=swap" rel="stylesheet">
  ```
- **UI-шрифт для текста и интерфейса:** `Inter` / `system-ui` (используется на официальном портале ФСП в связке с
  JetBrains Mono для длинных текстов, резюме и плотных форм).
