# HuntMe — Платформа обратного рекрутинга с верификацией ФСП

Инновационная платформа обратного рекрутинга для IT-специалистов с интеграцией верифицированных достижений Федерации
спортивного программирования (ФСП).

---

## 🚀 Быстрый старт для локальной разработки

Для удобной разработки стек разделен на два независимых процесса:

1. **Инфраструктура и бэкенд** (запускаются в фоне через Docker);
2. **Фронтенд** (запускается локально с поддержкой Vite Hot Module Replacement).

---

### Шаг 1. Запуск бэкенда и сервисов

Убедитесь, что установлены `docker` и `docker compose`. Затем в корне проекта выполните:

```bash
chmod +x ./start-services.sh
./start-services.sh
```

Скрипт автоматически запустит в фоне:

* **PostgreSQL (Database):** `localhost:5433` (основная БД приложения)
* **Keycloak (Auth):** [http://localhost:8080](http://localhost:8080) (авторизация с преднастроенным realm `huntme`)
* **Go Backend API:** [http://localhost:8081](http://localhost:8081)
* **Mailpit (Тестовая почта):** [http://localhost:8025](http://localhost:8025)

#### Полезные команды для бэкенда:

```bash
docker compose logs -f backend   # Просмотр логов бэкенда в реальном времени
docker compose ps               # Проверка статуса контейнеров
docker compose down             # Остановка всех сервисов
```

---

### Шаг 2. Запуск фронтенда

Откройте второй терминал и запустите dev-сервер фронтенда:

```bash
# Установка зависимостей (при первом запуске)
cd frontend
npm install

# Запуск сервера разработки с HMR
npm run dev
```

Или одной командой прямо из корня проекта:

```bash
npm run dev --prefix frontend
```

Приложение будет доступно по адресу:
👉 **[http://localhost:5173](http://localhost:5173)**

---

## 🛠 Полезные скрипты фронтенда

Все команды выполняются из директории `frontend/`:

* `npm run dev` — запуск локального dev-сервера (Vite).
* `npm run test:unit` — запуск unit-тестов через Vitest.
* `npm run type-check` — строгая проверка типов через `vue-tsc`.
* `npm run lint` — проверка и авто-исправление линтером ESLint.
* `npm run build` — полная проверка типов и production-сборка.

---

## 🐳 Запуск всего проекта целиком в Docker (Production-режим)

Если требуется поднять абсолютно все сервисы (включая собранный фронтенд в Nginx) одной командой:

```bash
docker compose up -d --build
```

В этом режиме единая точка входа доступна на стандартном порту:

* **Веб-приложение (Gateway Nginx):** [http://localhost](http://localhost)
